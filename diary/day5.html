Day 5 – Operators, Conditional Constructs & Loops

Date: 30 June 2026

Session Overview

Today's session focused on strengthening Python fundamentals by learning how Python performs calculations, comparisons, decision making and repetition. We explored various operators, conditional statements and looping constructs through several practical coding examples.

Arithmetic Operators

Learned Python arithmetic operators used for mathematical calculations:

  • Addition (+)
  • Subtraction (-)
  • Multiplication (*)
  • Division (/)
  • Floor Division (//)
  • Modulus (%)
  • Exponent (**)

Assignment Operators

Practiced assignment operators including:

  • =
  • +=
  • -=
  • *=
  • /=
  • //=
  • %=
  • **=

Comparison, Identity, Membership & Logical Operators

Learned how Python evaluates conditions using comparison operators, identity operators (is, is not), membership operators (in, not in) and logical operators (and, or, not).

Implemented a simple login validation program using logical operators.

Bitwise Operators

Explored binary representation of integers and practiced bitwise operators:

  • AND (&)
  • OR (|)
  • XOR (^)
  • Left Shift (<<)
  • Right Shift (>>)

The trainer also explained how negative numbers are represented using two's complement while performing right shift operations.

Conditional Constructs

Practiced writing programs using:

  • if
  • if-else
  • if-elif-else
  • Nested if statements

These constructs were used to implement authentication and promo-code validation systems.

Loops

Revised Python looping constructs and applied them to solve logical programming problems using both for and while loops.

Class Activity

The classroom activity was to implement a promo-code validation system similar to an e-commerce checkout page.

Using nested dictionaries and conditional statements, the program:

  • Accepted cart amount and promo code.
  • Validated the entered promo code.
  • Checked minimum purchase requirements.
  • Calculated percentage discounts.
  • Applied maximum discount limits.
  • Displayed the final payable amount.

Assignment

Solved the programming challenge "Another Brick in the Wall".

The objective was to determine which worker placed the final brick and how many bricks they placed using loops, conditional statements and incremental logic.

Discussion Points & Mini Tasks

  • Discussed the difference between Static Memory Management and Dynamic Memory Management, and why Python relies on dynamic memory allocation.
  • Learned that many security algorithms such as AES and SHA-256 internally make use of bitwise operations and bit shifting for efficient data processing.
  • Explored how the promo-code validation program could also be implemented using an if-elif-else ladder instead of nested dictionary lookups.

Key Learning Outcomes

  • Learned arithmetic and assignment operators.
  • Understood comparison, logical, identity and membership operators.
  • Explored bitwise operators and binary representation.
  • Practiced conditional statements.
  • Revised for and while loops.
  • Implemented a promo-code validation system.
  • Solved a logical programming assignment using loops.

Personal Reflection

Today's session covered many of the core building blocks of Python. Instead of learning individual syntax, I was able to combine operators, conditions and loops to solve practical programming problems. The promo-code system and brick placement assignment demonstrated how these concepts are used together in real applications.
